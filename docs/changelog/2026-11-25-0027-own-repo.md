# depot moves out of android-emu into its own repository

- **The repo.** `~/dev/depot` holds depot's history from android-emu, filtered to `depot/` (now the root) and its ADRs and changelogs. `origin` is `git@github.com:sohambagchi/depot.git`, not pushed yet.
- **The flake.** New `flake.nix` with `packages.depot`, `packages.depot-publish`, `checks.depot`, `nixosModules.depot`, `lib.depotEnv` and a dev shell. nixpkgs is locked to android-emu's revision.
- **depot-publish** (formerly `emu-publish`) uses an SDK of build tools only. It still refuses an APK without a "Check for updates" item.
- **Docs.** README.md, PROTOCOL.md and code comments point at this repo and `depot-publish`; the README shows the new flake input.
- **On malt.** The server is now built from `~/dev/depot#depot`.
- Rationale: see ADR [2026-11-25-0027-depot-is-its-own-repo](../adr/2026-11-25-0027-depot-is-its-own-repo.md)
